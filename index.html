⚙️ গুগল শিট (Google Sheet) কানেকশন কনফিগারেশন

কিভাবে গুগল শিট কানেক্ট করবেন:

  1. আপনার গুগল ড্রাইভে একটি নতুন Google Sheet তৈরি করুন।
  2. শিটের মেনু থেকে Extensions > Apps Script এ যান।
  3. আমাদের ফোল্ডারে থাকা google-apps-script.js ফাইলের সম্পূর্ণ কোড কপি করে সেখানে পেস্ট করে Save করুন।
  4. উপরে ডানদিকের Deploy > New Deployment এ ক্লিক করুন।
  5. Select type > Web app নির্বাচন করুন।
  6. Who has access: Anyone সিলেক্ট করে Deploy এ ক্লিক করুন।
  7. পেয়ে যাওয়া Web App URL টি নিচের বক্সে পেস্ট করে সেভ করুন।

* এই URL টি ব্রাউজারে সংরক্ষিত থাকবে। একবার বসালে যত স্টুডেন্ট ফর্ম জমা দিবে সবার তথ্য আপনার গুগল শিটে স্বয়ংক্রিয়ভাবে জমা হবে।
